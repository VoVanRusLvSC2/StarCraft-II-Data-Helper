A mapping is used only when DocumentInfo has no `file:` fallback. The raw declaration remains intact; the resolved fallback and mapping flag are reported separately. Existing path containment, duplicate-root ambiguity, archive metadata, transitive recursion and source SHA-256 checks apply to mapped files too. Missing or unsafe mappings remain Missing/InvalidFallback and cannot make the analysis Complete.
