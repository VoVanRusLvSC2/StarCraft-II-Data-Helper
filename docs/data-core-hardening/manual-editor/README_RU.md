# Ручная приёмка SC2 Editor — NOT_RUN

Эти XML независимо проходят XSD-валидацию, но не являются Editor-saved golden outputs. Автоматической проверки Editor в сессии нет. Не закрывать несохранённую сессию и не изменять исходные карты.

1. Записать версию Editor/SC2, зависимости и дату. Создать три отдельные пустые карты. Импортировать соответствующий Catalog в GameData либо воспроизвести декларации через XML-view Editor.
2. TokenActor: проверить загрузку обеих форм On, размещение AuditMarine, сохранение, повторное открытие и запуск. Проверить override токена в дочернем Actor. Сохранить фактический XML и журнал до/после.
3. ScalarArray: проверить LifeMax до/после удаления только равного scalar у ребёнка. EffectArray не изменять. Записать эффективное число и порядок эффектов после сохранения. XSD не доказывает append/replace/removed/reset.
4. Identity: проверить независимость AuditShared в трёх каталогах и разрешение EffectArray. Переименовать одну идентичность через Editor и сравнить изменённые носители ссылок.
5. Сохранить входную карту, результат операции, копию после повторного сохранения, XML, скриншоты/логи ошибок и результат запуска. PASS допустим лишь после реальной проверки; иначе NOT_RUN/FAIL.

Dependencies/override, enum/index/removed/reset, actor macro и GUI gamelink требуют отдельных карт, сохранённых Editor. Пока правила не подтверждены, они не входят в заявленную поддержку.
