# Точные ссылки Galaxy: продолжение этапа

Реализован общий лексический проход Galaxy для анализа, rename и merge. Поддержаны UnitCreate (аргумент типа Unit) и CatalogFieldValueGet/Set/GetAsInt (каталог и ID записи). Домены проверяются структурным индексом схемы. Точный неэкранированный строковый литерал заменяется по диапазону символов; вычисленное значение не переписывается.

Комментарии // и /* */ пропускаются. Литерал StringToText рассматривается как отображаемый текст. Прочие строки с известным ID остаются Blocking: без установленной грамматики безопасная замена не доказана. Неизвестный аргумент каталога/ID блокирует соответствующий домен. Разные каталоги с одинаковым ID сохраняют отдельную идентичность. Слияние по-прежнему пропускает глобально неоднозначные ID во внешних файлах.

Разрешаются простые глобальные const string, алиасы и конкатенация. Циклы и повторные объявления не разрешаются. Одноимённый параметр/локальная переменная либо присваивание отменяют доказательство значения глобальной константы. Неполная лексика, неверное число аргументов и определение функции с поддержанным именем дают неполное покрытие. Это ограниченный анализ, а не полный компилятор Galaxy: scopes, imports, пользовательские функции, builtins и dataflow ещё не завершены.

Мутации XML, SC2Triggers и Objects ещё используют прежние эвристики. Этот этап не закрывает полный контракт typed spans для всех форматов и не означает завершение исходной задачи.

Регрессии: rename меняет только ссылку Unit, сохраняя Actor с тем же ID, отображаемую строку и комментарии; неизвестный потребитель строки блокирует rename; merge сохраняет отображаемые строки и комментарии побайтно; скрытая глобальная константа, цикл алиасов и неполная лексика не доказывают значение. Существующие положительные fixtures теперь используют вызовы UnitCreate/CatalogFieldValueGet вместо произвольных присваиваний строк и StringToText; проверки обновления файлов и ссылок сохранены.

galaxy-merge-legacy-control.txt воспроизводит повреждение с прежним rewriteText: заменяются ссылка, StringToText и комментарии. Первый запуск galaxy-merge-before.txt был некорректным тестом окружения (cwd вне проекта, схема отсутствовала); он не используется как доказательство регрессии. galaxy-spans-before.txt содержит прежние ошибки rename. Итоговые результаты добавлены в STATUS/ACCEPTANCE после полного запуска.

Сигнатуры CatalogFieldValueGet/Set проверены по Blizzard natives.galaxy: https://raw.githubusercontent.com/grum/sc2-dev/master/Mods/Core.SC2Mod/Base.SC2Data/TriggerLibs/natives.galaxy . GetAsInt остаётся явно поддержанным helper-вызовом ограниченной грамматики, без вывода о произвольных обёртках.

Предыдущий portable data-core-hardening-20260927 и показатели PERFORMANCE.md относятся к предыдущему этапу. Для нового этапа нужен отдельный пакет; старый пакет не объявляется обновлённым.
Вычисление каждого выражения ограничено: глубина 32, до 4096 вызовов evaluator и длина результата 4096 символов. Превышение даёт Unknown, без переписывания. Регрессия galaxy-expansion-before.txt воспроизводит неограниченный результат удваивающейся цепочки; также проверяются 64 вложенные пары скобок.

Финальные проверки после исправления границ: Debug/Release 4/4 CTest PASS, в каждом core 131 passed / 0 failed / 4 skipped. Debug 242.58 s, Release 79.74 s. Ошибка Debug LNK1163 была устранена повторной компиляцией конкретного объектного файла; исходники для этого не менялись. Успешные логи: spans-debug-rebuilt-verified.txt, spans-release-verified.txt.

Свежий probe на контрольном XML: Complete, один объект, один Safe candidate. OptimizeFolder на этой отдельной fixture: success true, один preview candidate, ноль удалений/слияний; SHA файла сохранился. Обработка добавляет структурную схему, inherited typed/provenance edges, лексический проход Galaxy и консервативные ссылки при неизвестных каталогах/выражениях. Память почти удвоилась на большой карте относительно baseline и остаётся нерешённым ограничением. Следующая проверка производительности должна разделить стоимость загрузки схемы, resolver, лексики и построения графа; не выдавать единичный замер за устойчивое ускорение.

Обе текущие карты Partial из-за незагруженных объявленных dependencies; новые lexical coverage issues также сохранены в incomplete_sources. Нулевое Safe не доказывает использование всех объектов: зависимые операции блокируются неполным анализом. Raw JSON с Unknown reasons: benchmark/galaxy-*.json. Duration завершается до дополнительного построения UnifiedReferenceIndex для подсчёта records; peak измерен после этого прохода, как у baseline. Дополнительный объект — default без id. Предыдущие PERFORMANCE.md и benchmark/*-final.json относятся к предыдущему этапу.
